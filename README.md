# Coffee Elite · Front

Portada de la web de **Coffee Elite**, con el diseño "Pistacho y oro": toldo de rayas, vitrina en arco con la foto del croissant, taza de porcelana del latte de pistacho y cinta con la carta.

Es HTML, CSS y un poco de JavaScript, sin dependencias ni paso de compilación. Para verla, abre `index.html` en el navegador.

## Archivos

- `index.html`: la portada.
- `assets/css/estilos.css`: estilos. Hay dos diseños: escritorio (3 columnas) y, desde 1099 px hacia abajo, tablet y celular (apilado).
- `assets/js/menu.js`: menú desplegable del celular.
- `assets/img/`: foto del croissant y favicon.

## Pendiente

- Cambiar `[Horario]` por el horario real.
- Los enlaces `#carta`, `#pasteleria`, `#nosotros`, `#ubicacion` y `#reservas` apuntan a secciones que todavía no existen.
- Las animaciones (vapor, sello giratorio, toldo y cinta) se desactivan si el visitante tiene activado "reducir movimiento".
